# Кейс 1: Анализ рыночных долей децентрализованных бирж (DEX)

## 📌 Бизнес-задача
Рассчитать динамику изменения ежемесячных объемов торгов (Volume) в долларах США для топ-протоколов за последние 6 месяцев. Проект позволяет выявить тренды доминирования конкретных дексов (например, Uniswap) на рынке.

## 🛠️ Технические особенности запроса
- Использование готовой абстракции `dex.trades` (слой Spellbook в Dune).
- Приведение типов `CAST(... AS DOUBLE)` для ускорения математических вычислений СУБД без потери центов.
- Динамический фильтр времени через `INTERVAL '6' month` (запрос автоматически актуален при каждом запуске).
- Использование ленивой группировки `GROUP BY 1, 2`.
