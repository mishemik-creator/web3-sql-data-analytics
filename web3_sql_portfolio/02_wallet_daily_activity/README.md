# Кейс 2: Мониторинг метрик UAW и вовлеченности пользователей

## 📌 Бизнес-задача
Рассчитать посуточную статистику уникальных активных кошельков (UAW) в сети Ethereum и определить среднее количество транзакций на одного пользователя. Запрос отфильтровывает и подсвечивает только аномальные дни, когда средняя активность превышала 5 транзакций на человека (маркеры аирдропов, хайп-событий или бот-атак).

## 🛠️ Технические особенности запроса
- Использование оператора `DISTINCT` внутри агрегатора `COUNT` для точного расчета уникальных адресов.
- Сложная пост-фильтрация через блок `HAVING` с дублированием расчетной математической формулы.
- Обертывание зарезервированного имени поля `"to"` (при необходимости) и безопасные типы вычислений.
