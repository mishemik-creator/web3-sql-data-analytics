# Кейс 3: Аналитика удержания токенов после аирдропа (Arbitrum Case Study)

## 📌 Бизнес-задача
Сегментировать получателей аирдропа на две группы: «Дамперы» (кто сразу продал/перевел токены на биржу) и «Холдеры» (кто удерживает актив). Посчитать общее число кошельков, суммарные объемы токенов и средний размер полученного аирдропа для каждой группы.

## 🛠️ Технические особенности запроса
- Использование `LEFT JOIN` с тройным условием склейки (`ON`), учитывающим хронологию (`t.block_time > a.block_time`) и адрес смарт-контракта токена.
- Применение оператора логического ветвления `CASE WHEN` для поведенческого скоринга кошельков на лету.
- Проверка связи таблиц через оператор `IS NOT NULL`.
- Корректная обработка разрядности Wei (деление на `1e18`) для токена ARB.
