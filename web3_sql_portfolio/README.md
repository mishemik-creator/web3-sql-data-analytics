# Web3 SQL Analytics Portfolio 🚀

Добро пожаловать в мое портфолио! Здесь собраны практические кейсы по анализу блокчейн-данных (Ethereum, Base, Arbitrum). Все запросы написаны на диалекте **Dune SQL (Trino Engine)** и оптимизированы для работы с реальными смарт-контрактами.

## 📂 Структура репозитория

Каждая папка содержит `.sql` файл с кодом и подробный разбор бизнес-логики:

1. **`01_dex_monthly_volume/`** — Анализ ежемесячных объемов торгов и долей рынка децентрализованных бирж (DEX).
2. **`02_wallet_daily_activity/`** — Мониторинг метрик UAW (уникальные активные кошельки) и детекция аномальной активности пользователей.
3. **`03_airdrop_holder_behavior/`** — Исследование удержания токенов (Hold vs Dump) после масштабных аирдропов.

---

## 🛠️ Технический стек и навыки
- **Инструменты:** Dune Analytics, Flipside Crypto, GitHub.
- **Продвинутый SQL:** Временные таблицы (`WITH / CTE`), Оконные функции (`ROW_NUMBER() OVER`, кумулятивное суммирование), Сложная фильтрация агрегированных групп (`HAVING`), Логическое ветвление (`CASE WHEN`), Динамическая фильтрация временных интервалов (`DATE_TRUNC`, `INTERVAL`).
- **Web3 Доменные знания:** Архитектура смарт-контрактов, разрядность чисел (Wei, Decimals), стандарты ERC-20 (токены) и ERC-721 (NFT).
